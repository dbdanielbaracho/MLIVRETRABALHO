# Plano Mestre de Execução — MLIVRETRABALHO

## Regra principal
O aplicativo celular é o produto operacional principal. O web é complementar.

## Método de construção
Cada capacidade crítica deve ser construída como fatia vertical:

**Jornada mobile → UX → requisito → API → banco → implementação mobile → testes → integração → evidência.**

## Marco M1 — jornada profissional mínima
1. cadastro/login;
2. perfil;
3. oportunidades;
4. interesse/aceite;
5. confirmação;
6. agenda;
7. check-in;
8. trabalho em andamento;
9. check-out;
10. conclusão;
11. ganhos;
12. avaliação;
13. Work Passport.

## Marco M2 — jornada empresa mínima
Empresa/unidade → necessidade → oportunidade → candidatos/recomendação → confirmação → presença → substituição → conclusão → avaliação → pagamento.

## Depois
Matching Engine → Allocation Engine → Pools → Scores → Work Passport → Planner → pagamentos → Trust & Safety → Copilot/IA → web empresarial → analytics → auditoria adversarial → deploy → Production Truth Gate → piloto → expansão.

## Definition of Done
Nenhum item é concluído apenas por existir em código. Deve possuir requisito rastreável, testes adequados, commit/SHA, integração e, quando aplicável, deploy e evidência real.
